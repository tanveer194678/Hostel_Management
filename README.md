# 🏨 Hostel Management System

A web-based Hostel Management System built with Django to simplify hostel administration, student management, and room allocation.

## Features

- 👤 Student Registration
- 🔐 Secure Login & Authentication
- 🏠 Hostel Room Management
- 📋 Student Information Management
- 🗄 SQLite Database Integration
- 📱 Responsive Web Interface

## Tech Stack

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Project Structure

```
hostel-management-system/
│
├── app/
├── myproject/

├── requirements.txt
└── README.md
```

## Installation

```bash
git clone https://github.com/tanveer194678/hostel-management-system.git
cd hostel-management-system

pip install -r requirements.txt

python manage.py runserver
```
